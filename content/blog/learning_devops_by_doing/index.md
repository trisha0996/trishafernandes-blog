# Introduction

Over the next few months, I’m building out a personal DevOps lab using a Raspberry Pi 5. It’s not a flashy project or a fancy setup - just a focused attempt to actually *understand* the tools and systems I work with every day.

I work in DevOps, but like many people in this field, there are gaps in my foundational knowledge. I can use cloud platforms, deploy apps, and manage infrastructure — but I don’t always fully understand what’s happening underneath. I want to change that.

This blog will be my way of keeping track of what I’m learning as I go.


# Why Raspberry Pi?

I don’t have the space or budget for a full server setup at home, but the Raspberry Pi offers a powerful and affordable alternative. It’s compact yet capable of running everything from Linux and Docker to Kubernetes, monitoring stacks, and automation tools — making it an ideal platform for building a hands-on lab and learning real-world DevOps skills.

# What I’m Building

I’ve broken the project down into phases — each one focused on learning and building a specific piece of the DevOps puzzle:

- Setting up a Linux server from scratch

- Running Docker and managing containers

- Hosting services and deploying apps

- Adding TLS/HTTPS, security, and firewall rules

- Monitoring with Prometheus and Grafana

- Learning Kubernetes (with k3s) and microservices

- Creating CI/CD pipelines and GitOps workflows

- Automating infrastructure with Ansible

- Setting up NAS storage with NFS

- Using Vagrant to simulate virtual infrastructure

- Experimenting, breaking, fixing — and documenting it all

Each blog post will walk through what I’ve done, why it matters, and how it connects to real-world DevOps work.
